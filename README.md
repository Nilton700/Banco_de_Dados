# 🗄️ Banco de Dados

Repositório dedicado aos estudos e às atividades desenvolvidas na disciplina de **Banco de Dados**, do curso de **Engenharia de Software**.

A disciplina tem como objetivo compreender os fundamentos da modelagem, criação, organização e manipulação de bancos de dados, utilizando a linguagem SQL com foco no MySQL para armazenar, consultar e gerenciar informações de maneira estruturada.

## 🎯 Objetivos da Disciplina

- Compreender os conceitos fundamentais de bancos de dados relacionais.
- Aprender a criar e estruturar bancos de dados.
- Desenvolver consultas para recuperar e filtrar informações.
- Manipular registros por meio de comandos SQL.
- Estabelecer relacionamentos entre tabelas.
- Aplicar restrições para garantir a integridade dos dados.
- Desenvolver soluções para armazenamento e gerenciamento de informações.

## 📚 Conteúdos Estudados

Os principais conteúdos abordados na disciplina incluem:

- **Fundamentos de Banco de Dados:** conceitos de tabelas, registros, campos e bancos de dados relacionais.
- **DDL (Data Definition Language):** criação e alteração de estruturas com comandos como `CREATE`, `ALTER` e `DROP`.
- **DML (Data Manipulation Language):** inserção, atualização e exclusão de registros com `INSERT`, `UPDATE` e `DELETE`.
- **Consultas SQL:** utilização de `SELECT` para recuperar informações.
- **Filtros e ordenação:** aplicação de `WHERE`, `LIKE`, `IN` e `ORDER BY`.
- **Chaves primárias e estrangeiras:** identificação de registros e estabelecimento de relacionamentos entre tabelas.
- **Restrições de integridade:** utilização de `NOT NULL`, `UNIQUE`, `CHECK` e `DEFAULT`.
- **Relacionamentos entre tabelas:** organização dos dados por meio de associações entre entidades.
- **Modelagem de dados:** estruturação de tabelas e definição de relacionamentos.
- **Funções e recursos do MySQL:** utilização de recursos para manipular e consultar dados.
